## 18. Warnings and limitations

4. The isolated FFmpeg build has `hevc_nvenc` but not `libx265`; the existing NVENC reference harness architecture was used and no component was installed.
5. FFmpeg emitted an encoder warning that `yuv420p10le` was incompatible with `hevc_nvenc` and auto-selected `p010le`. Final ffprobe confirms the required `yuv420p10le` output signaling.
6. The HDR source decode log contained an input-container `Unsupported encoding type` warning for non-video material streams. The selected video decoded successfully; final render, ffprobe, and NVDEC playback passed.
7. The strict shadow plateau test failed at `5.134461%`, just above the established `5%` threshold. No correction was made.
8. The full overlap bbox is not expected to be numerically identical at feather rows/columns; the exact `mask==0` core invariance is the protected HDR-master criterion.
