## 1. Implementation

Modified production file:

- `src/auto_openmatte/core/transfer_functions.py`

Added:

- `_PQ_OETF_LUT_SIZE = 65536`
- `build_pq_oetf_sqrt_lut()`
- `_get_pq_oetf_sqrt_lut()` with `lru_cache(maxsize=1)`
- `pq_oetf_sqrt_lut()` with linear interpolation

The LUT is generated from the reference `pq_oetf()` function. Its input coordinates are:

```text
t = linspace(0, 1, 65536)
input = t²
```

This allocates more samples in the dark region, where PQ changes fastest. Lookup performs:

```text
normalized = clip(luminance / 10000, 0, 1)
t = sqrt(normalized)
linear interpolation between neighboring LUT entries
```

Unchanged:

- `pq_oetf()` mathematical reference
- `pq_eotf()`
- BT.1886 linearization
- BT.709 → BT.2020 gamut conversion
- BT.2020 luminance weights
- luminance curve LUT from P2.15
- low-end bridge and black handling
- ratio calculation
- geometry and ROI
- fitting, sampling, and encoder

## 10. Production PQ OETF Benchmark

Actual 3-channel production ROI: `560 × 3840 × 3 = 6,451,200` samples.
Each variant was run 10 times after warmup; table reports median, minimum, and maximum.

### Direct PQ OETF

| Variant | Median ms | Min ms | Max ms | FPS-equivalent | Speedup |
|---------|----------:|-------:|-------:|---------------:|--------:|
| OLD mathematical `pq_oetf` | 244.1 | 233.0 | 259.5 | 4.10 | 1.00× |
| NEW sqrt-LUT `pq_oetf_sqrt_lut` | 143.4 | 134.3 | 160.6 | 6.97 | **1.70×** |

### Full production transform

| Variant | Median ms | Min ms | Max ms | FPS | Speedup |
|---------|----------:|-------:|-------:|----:|--------:|
| OLD mathematical PQ | 482.8 | 469.9 | 495.9 | 2.07 | 1.00× |
| NEW sqrt-LUT PQ | 354.6 | 349.4 | 395.4 | 2.82 | **1.36×** |

Measured full-transform reduction: **128.2 ms/frame**, or **26.6% faster**.

The direct PQ speedup is lower than the isolated P2.16 single-channel estimate because this benchmark measures the actual 3-channel production array and includes the complete LUT interpolation path.
