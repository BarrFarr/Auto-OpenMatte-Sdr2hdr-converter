# P2.15: Curve LUT Production Integration Report

## 1. Implementation

Production `apply_luminance_curve()` now uses a 65,536-entry precomputed LUT for the fitted range, replacing the expensive `log10() → PchipInterpolator → pow10()` path.

**Modified files:**
- `src/auto_openmatte/processing/luminance.py` — added `build_curve_lut()`, `apply_luminance_curve()` (LUT path), `apply_luminance_curve_reference()` (PCHIP preserved)
- `src/auto_openmatte/processing/transform.py` — `apply_shot_transform()` accepts `prebuilt_lut` kwarg
- `src/auto_openmatte/pipeline/compose.py` — `composite_extend()` builds LUT once, passes to all sub-calls

**New functions:**
- `build_curve_lut(curve, n_entries=65536) → dict` — builds LUT from control points
- `apply_luminance_curve_reference(sdr, curve)` — original PCHIP path for validation

## 2. LUT Lifecycle

```
fit_curve (per shot)
    ↓
build_curve_lut() — ONCE per fitted curve
    ↓
apply_luminance_curve(..., prebuilt_lut=lut) — reused for ALL frames of shot
    ↓
next shot → new curve → new LUT
```

- LUT is **NOT** rebuilt per frame
- `composite_extend()` builds LUT once at top and passes to all `apply_shot_transform()` calls
- `apply_shot_transform()` builds LUT only if `prebuilt_lut=None` (fallback safety)
